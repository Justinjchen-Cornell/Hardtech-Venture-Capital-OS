## 1. 背景与目标

**业务目标**：在成都寻找并投资早中期硬科技项目（筛选→尽调→估值→投决全流程）。

**问题**：11 本书单（穷查理宝典/硬科技浪潮/守正/下一个风口/高科技营销魔法/我的PE观/高增长科技股投资法/价值投资3.0/Investment Valuation/私募股权投资和尽职调查手册/风险投资交易）是"会背书的顾问"，不是"能找到项目的系统"。知识必须变成三层机器可调用的结构 + 一层业务流水线，才能支撑长期、一致、可追溯的投资决策。

**成功标准**（3 个月内可检验）：
1. 11 本书全部转成可调用的 skill（其中 9 本已有 MD 原料；2 本待补源）
2. 《穷查理宝典》精读完成，产出"个人投资宪法"初稿（= 06.VC/CLAUDE.md 内核）
3. 3 个核心子代理（赛道扫描/技术尽调/估值分析）可独立执行任务
4. 成都项目池建立，≥10 个种子项目入池（含郑宗良天线项目），≥1 个走完端到端管线
5. GitHub repo（Hardtech-Venture-Capital-OS）持续同步，内容合规

## 4. 总体架构：知识侧三层 + 业务侧一层

```
09.BiZZ/06.VC/                          ← 项目根（本地 vault）
├── CLAUDE.md                           【层1】投资哲学+铁律（项目级常驻，<200行）
├── 01.Book/                            原书 PDF/EPUB（版权，不入 repo）
├── 02.MD/                              已转文本 9 本（版权，不入 repo）
├── 03.Skills/                          【层2】book-to-skill 产物（入 repo）
├── 04.Projects/                        【层4】项目池（卡片+材料，脱敏后入 repo）
├── 05.Pipeline/                        流水线状态机 + 精读进度
└── docs/superpowers/                   设计文档 + PLAN.md（入 repo）

~/.claude/
├── skills/                             【层2】全局技能（11 本书 + book-to-skill）
└── agents/                             【层3】专项子代理（全局可用）
    ├── sector-scanner.md      赛道扫描员    model: flash
    ├── tech-dd.md             技术尽调员    model: pro
    ├── valuation-analyst.md   估值分析师    model: pro
    └── (后置) deal-negotiator.md / ic-memo-writer.md
```

**分层职责**：
- CLAUDE.md：每条会话自动加载，只放最稳定的决策纪律（投资哲学、铁律、成都偏好、评估流程），<200 行
- Skills：按需加载，书内容只在被问到对应章节时进入上下文
- Subagents：独立上下文窗口，承担大规模读取任务（200 页 BP、专利 PDF），不污染主会话
- 业务层：项目源渠道、项目卡片、状态机，让知识落在项目上

### 5.2 预处理步骤（每本：用 Claude Code 读目录页重建标题结构）

1. 读每本 MD 的目录区（`目 录`/`Table of Contents`）
2. 识别章节边界（正文中的章节标题关键词，注意标题可能无 # 前缀）
3. 重写为规范 Markdown 标题（`## 第N章` / `## Chapter N`）
4. Investment Valuation 额外执行：去 NUL 字节 + 分 3 块（内在估值/相对+期权/私有企业）
5. 输出到 `02.MD/structured/` 子目录，保留原文件

### 5.3 转换与验证（试点→批量）

1. **试点 3 本**：穷查理宝典 / 守正 / 硬科技浪潮（结构相对清晰 + 认知底座优先）
2. **验证协议**：每本转完后问 3 个已知答案的问题，确认无乱编（如："能力圈的定义原文是什么？"）
3. **批量转**：剩余 6 本
4. **缺 2 本**：高科技营销魔法、风险投资交易——待补源文件（EPUB 优先）

### 5.4 成本估算（按 deepseek-v4 路由）

- MD 已为文本：无 OCR 成本；预处理+转换 11 本合计约 $1-3（远低于原方案 $11 估算）
- 每次调用只加载相关章节，长期 token 使用量可控

## 8. 成都 4+6 候选地图（Q1 已定：不预设焦点，先调研）

**决策（2026-08-17）**：因对成都实际情况了解不足，不锁定具体行业焦点。4+6 作为**候选地图**，系统结构保持赛道无关（sector-agnostic），通过实地调研逐步验证收敛。

**候选地图（待验证）**：
- 4 新兴：新能源 / 新材料 / 低空经济 / 航空航天
- 6 未来：量子科技 / 生物制造 / 脑机接口 / 氢能与核聚变 / 具身智能 / 第六代移动通信

**验证路径**（代替行业预设）：
1. 项目池优先收录上述 10 个方向的成都项目，用数据（项目数量/质量/融资活跃度）说话
2. sector-scanner 子代理对所有候选方向输出同一套评估模板（ESK/范式/周期/鸿沟），横向可比
3. 累计 ≥10 个样本后，按"样本密集度 × 成都禀赋 × 认知可及性"收敛主轴，再写入 CLAUDE.md 铁律

**郑宗良天线项目**：暂不贴行业标签，作为低空/航空/6G 交叉候选样本收录（不预设结论）。
