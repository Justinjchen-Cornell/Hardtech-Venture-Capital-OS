# 数据源连接器映射（中国版）

> 定位：Anthropic financial-services 11 个 MCP 连接器的国内替代映射（2026-08-19 集成）。
> 原则：按管线环节挂接数据源，一个环节一个主源 + 一个交叉验证源；免费优先，订阅按需。

## 管线环节 × 数据源

| 管线环节 | 主源 | 交叉验证 | 查什么 |
|:--|:--|:--|:--|
| **赛道扫描**（sector-scanner） | 政府政策库（发改委/工信部/科技部）· 券商研报（慧博/萝卜投研） | 行业白皮书（各协会） | 政策风向、TAM 估算、国产替代空间 |
| **项目发现**（deal-sourcing） | 烯牛数据（融资事件）· IT桔子 | 企名片·园区官网（天府国际生物城/中国科学城） | 新融资/新公司/新团队；入驻企业 |
| **工商与股权**（尽调） | 企查查·天眼查 | 见微数据（工商+司法） | 股权结构/历史变更/司法风险/实控人 |
| **知识产权**（IP 核查） | 智慧芽·佰腾 | 国家知识产权局（免费） | 专利质量/权属/竞品布局/职务发明 |
| **技术前沿**（tech-dd） | arXiv·知网·学术会议 | 高校官网（电子科大/川大/西南交大） | 技术路线代际/团队学术实力/转化项目 |
| **财务与估值**（valuation） | Wind·同花顺 iFinD | 巨潮资讯（上市公司公告） | 可比公司/行业数据/退出参照 |
| **投后监控**（portfolio-monitoring） | 被投公司财务包（直接提供） | 企查查（股权/融资异动）+ 新闻 | 里程碑验证/融资进展/异常信号 |
| **宏观与周期**（next-windfall） | 国家统计局·海关总署 | 央行/工信部月报 | 周期定位/产能/出口数据 |

## 使用纪律
- **一手数据优先**：对账单/合同/访谈 > 第三方库 > 二手研报
- 第三方库数据用于"发现线索"，不用于"下结论"——结论必须回到一手验证（元事实 L3+）
- 每条引用标注来源+获取日期（可追溯）；无法验证标"未证实"
- 订阅取舍：先免费源跑通流程，缺口出现再升级付费
