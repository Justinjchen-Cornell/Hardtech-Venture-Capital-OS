# 每周工作流（Agent 驱动的主动出击）

> 目标：体系从"被动响应"升级为"主动出击"——扫项目、备会、审质量。

## 每周节奏

| 时段 | 动作 | Agent | 产出 |
|:--|:--|:--|:--|
| 周一 | deal-sourcing 扫描重点赛道（中国 4+6 候选轮换）| deal-sourcing | 项目清单（入池/建档）|
| 周一 | 上周扫描结果回流（RWP）| — | 执行日志更新 |
| 周二-周四 | 约见创始人 → 会前 15 分钟简报 | meeting-prep | 一页纸简报 + 访谈问题包 |
| 周五 | 项目评审 → IC 备忘录审计 | ic-memo-auditor | 审计结论 + 3 个修改建议 |
| 周五 | 信息批量收集 + RWP 复盘 | — | 执行日志 + 回写 |

## 触发与纪律
- 派发原则：信息足够才派发（不全则标注待材料，不硬凑）
- deal-sourcing 扫描范围轮换（每周一个 4+6 方向，8 周覆盖）
- 项目入池一律用项目卡模板（含元事实清单）
- 审计不通过 = 备忘录退回修改，不投决

## 脚本辅助（可选）
- scripts/deal-sourcing-helper.py：生成关键词组合 + 启动本地抓取脚本（fetch_so.sh + parse*）
- 新闻提醒：关键事件命中规则见场景矩阵（即时分析）
