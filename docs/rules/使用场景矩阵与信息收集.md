## 二、工具与清单生成（项目过程中的可执行物）

每个项目/场景可生成 4 类工具：

### T1 工作计划与重点（项目立项时）
```
{项目名} 工作计划
- 阶段目标：{当前决策门}
- 本周重点：{3 项，按优先级}
- 责任人：{谁推进什么}
- 截止：{日期}
```

### T2 关键信息提醒清单（每个项目常驻）
```
{项目名} 关键信息提醒
🔴 最高优先级（影响估值/结论）：
  - {元事实 L1 待验证项}（如：订单证据等级）
🟡 高优先级（影响判断）：
  - {待验证项}
🟢 常规（背景更新）：
  - {行业动态}
```

### T3 优先级排序（尽调任务）
按"影响 × 紧迫度"四象限排序：
```
影响大+紧迫 → 现在做（订单证据等级核查）
影响大+不紧迫 → 本周做（转化模式推动）
影响小+紧迫 → 今天做（材料索取）
影响小+不紧迫 → 记录（行业背景更新）
```

### T4 提醒触发规则（每项目）
```
- 元事实证据等级变化 → 即时提醒 + 失败概率重估
- 关键事件命中（见下）→ 即时提醒 + 快评
- 决策门状态变化 → 即时提醒
- 每周五 → 批量回顾（RWP 复盘）
```

## 三、信息收集机制（定期 vs 即时——混合模式）

### 设计原则
- **定期批量**（低成本，沉淀不打扰）：渠道轮询/新闻扫描/企查查更新 → 每周五或每日固定时段 → 沉淀到项目池/赛道文件
- **即时分析**（高价值，事件驱动）：关键事件命中 → 马上分析 + 提醒 → 产出事件快评

### 关键事件触发规则（命中即即时分析）
| 类别 | 触发条件 | 动作 |
|:--|:--|:--|
| 目标赛道公司 | 低空/ISAC/天线相关公司融资、并购、新品 | sector-scanner 快评（半页）|
| 竞争对手 | 信维/硕贝德/华为天线部门动态 | 竞争格局更新 + 郑宗良影响评估 |
| 政策 | 低空经济/通感一体政策、标准发布 | 政策影响快评（+社会价值 S 重估）|
| 关键人 | 郑宗良/团队动态（全职/职务变动）| 元事实更新 + 失败概率重估 |
| 订单相关 | 意向客户动态/招标信息 | 订单三连核查触发 |

### 非关键事件处理
- 未命中触发规则 → 仅记录（入库），不打扰，周五批量回顾时纳入

### 收集频率建议
- 每日（5 分钟）：目标赛道新闻标题扫描（命中→即时分析）
- 每周（30 分钟）：渠道轮询 + 企查查新增融资 + RWP 复盘
- 每月（2 小时）：赛道评估刷新（行研 13 要素）+ 项目池状态机更新
