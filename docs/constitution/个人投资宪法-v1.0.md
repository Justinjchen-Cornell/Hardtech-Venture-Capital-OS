# 个人投资宪法 v1.0（2026-08-17 成稿）

> 由《穷查理宝典》精读单元 1-7 逐条沉淀（铁律 0-6），单元 8 汇总成稿。
> 用途：成为 `06.VC/CLAUDE.md` 内核；每条铁律均有对应概念页（见附录）。

---

## 总纲

**我们不是要成为非常聪明的投资人，而是要持续地避免变成蠢货。** 判断力的本质是：用多学科模型组合看项目（铁律 0），只在能力圈内出手（铁律 1），先证明它不会死再谈它为什么活（铁律 2），对抗自己的认知污染（铁律 3），用程序守住投后纪律（铁律 4），把弹药留给确认的好球（铁律 5），用基因视角看待竞争（铁律 6）。

## 第 0 条 多元思维模型（单元 1）

1. 禁止用单一思维模型下投决；每个项目必须 ≥3 个学科视角
2. 模型同向叠加 = Lollapalooza（放大判断）；互相抵消 = 否决信号
3. 验证顺序：技术 → 市场 → 团队（低成本快淘汰）
4. 权重顺序：团队 > 市场 > 技术（下决心时，三把尺）

## 第 1 条 三选项分类 / 能力圈（单元 2）

1. 每个项目先归入：**可以 / 不行 / 太难**——三选项，没有第四项
2. 归入"太难"：无论多热门，不投（禁止 FOMO 改判）
3. 归入"可以"：必须能说出能力圈边界（说不出 = 实际"太难"）
4. 判断"能不能学会"比"现在懂不懂"更重要
5. 剪草工原理：不追全赛道，在成都窄链路做到最懂

## 第 2 条 逆向思维 / 死亡清单（单元 3）

1. 每个项目先问"100% 会死在哪"，再问"凭什么活下来"
2. 六大死法全过一遍：现金流断裂 / 团队内讧 / 合规事故 / 技术被颠覆 / 伪需求 / 道德风险
3. 任一死法无法排除 = 不出手（投决是排除法，不是证明法）
4. 死因倒推：现金流断裂 ← 无订单 ← 市场验证未做——验证动作提前做掉
5. 尽调防"司机知识"：问为什么/边界/反例三连，区分真懂与复述

## 第 3 条 误判心理学检查清单（单元 4）

1. 识别 → 追问动机 → 拒绝行动（三步解毒法）
2. 激励错位：先看利益不看承诺（"诉诸利益，而非诉诸理性"）
3. 热点市场双重陷阱：认知污染 + 交易恶化——"投不进"是市场在执行纪律；追问"市场知道什么我不知道的"
4. 避免不一致：已投项目设"反转触发器"，信号触发无条件降级
5. BP 数字默认打五折再听；投决材料强制写"反向观点"栏
6. 欢迎坏消息（波斯信使综合征防范）："未必要有希望才能够坚持"

## 第 4 条 投后管理纪律（单元 5）

1. 投后死亡螺旋：浮亏 → 不肯止损 → 抱有幻想 → 隐瞒问题 → 恶化——识别即干预
2. 破局三环节：① 反转触发器（投前写死）② 坏消息上报机制（报坏消息不受罚）③ 独立裁判（评审人 ≠ 拍板人；可用机器子代理）
3. 决策只向前看，不问已付出什么（沉没成本无效）
4. "人靠不住时靠程序"：投后监控用检查清单程序化执行

## 第 5 条 出手纪律 / 弹药纪律（单元 6）

1. 好球 = 好项目 × 好价格 × 好时机，三条件缺一不可
2. 集中投资前提：能力圈内 + 死亡清单全排除 + 好价格
3. 出手五连问：能力圈？好价格？时机？份额够？弹药够（含后续跟投）
4. 弹药守恒：乱出手（不可逆）> 坐失良机（可逆）——宁可错过，不可乱投
5. 少投、重注、深跟（精选 5-8 个项目，而非撒网 20 个）
6. 接触 ≠ 出手：项目池持续运转，出手频率每年 2-3 个

## 第 6 条 竞争性毁灭（单元 7）

1. 判断项目 = 判断其承载的技术路线/模式基因在明天环境中的适应度（载体可死，基因延续）
2. 竞争性毁灭三问：① 适应特征（人无我有）② 环境方向（格局/代际朝哪选）③ 恐龙 or 哺乳动物
3. 真正的对手是"路线"不是"公司"
4. 个人阅读路线：自私的基因 → 聪明的投资者 → 影响力 → 只有偏执狂才能生存

## 执行机制

- **项目初筛（60 秒）**：第 1 条三选项 → 归"太难"直接出局
- **初步评估（半天）**：第 0 条三模型视角 + 第 2 条死亡清单 + 第 6 条三问
- **深度尽调（1-2 周）**：第 2 条逐条验证 + 第 3 条检查（反向观点栏）+ 司机知识三问
- **投决（1 天）**：第 5 条出手五连问 + 第 3 条反向观点强制提交
- **投后（持续）**：第 4 条三环节 + 反转触发器监控
- **自我审计（每季度）**：过去 3 个月每个决定，用第 3 条清单复盘"当时中了哪种倾向"
