# Pipeline — 投资决策执行管线

> 从"扫赛道"到"投后管理"的可执行工作流。核心文件：

| 文件 | 用途 |
|:--|:--|
| 管线执行协议.md | 7 步 SOP（输入/处理/输出/交接/异常）+ 决策门 + 状态机 + 五阶段映射 |
| 投资生命周期五阶段.md | 投资人视角的 5 阶段模型（赛道技术转化→团队背调→估值谈判→投决执行→投后）|
| 每周工作流.md | Agent 驱动的每周节奏（deal-sourcing → meeting-prep → ic-memo-auditor）|
| templates/ | 10 个输出模板（01-赛道评估 … 10-团队与KeyPerson背调）|

## 五阶段速览

```
阶段 1  赛道评估 · 技术尽调 · 转化评估 ·【技术与市场印证】
阶段 2  【团队与 Key Person 背调】（独立背调阶段）
阶段 3  估值 · 交易结构 · 谈判
阶段 4  投决与执行（决策门 5 道 + 审计）
阶段 5  投后管理（五大监控 + 退出）
```
