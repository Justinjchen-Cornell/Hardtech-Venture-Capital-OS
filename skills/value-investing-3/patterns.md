# 决策模式集（patterns）

## P1 BMP 三要素评估（成长期企业）
B（大市场/小份额/长优势各1-5）→ M（大德/大才）→ P（前瞻 PE+潜在盈利）

## P2 潜在盈利能力两步法
①预测板块 3 年收入（保守延续历史增速）②调整利润率（研发资本化/一次性剔除）→ 前瞻 PE

## P3 估值口径检查
抛弃市净率/均值回归；PE 必须前瞻（3年）+潜在盈利（非每股收益）

## P4 双时点分层（早期 vs 成长期）
无收入（CRL<4）：MatMax + 里程碑；有收入雏形（CRL≥5）：BMP + 潜在盈利

## P5 订单数据快检（实战）
意向/合同/预付款三连 → 年收入粗算（数量×单价）→ 毛利=定价权信号 → CRL 重估 → 市场尺校验（vs IPO 10 亿）
