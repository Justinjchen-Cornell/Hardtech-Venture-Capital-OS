# 决策表（cheatsheet）

## 审计范围选择
| 范围 | 何时用 | 深度 |
|:--|:--|:--|
| 选区 | 快速抽查 | 公式级 |
| 工作表 | 单表审核 | 公式级 |
| 整个模型 | 投决前/报告前 | 公式级+完整性 |

## 检查顺序（整个模型）
1. 公式错误+硬编码（全表扫）
2. 资产负债表平衡（不平衡=先修）
3. 现金勾稽（CF 期末现金 = BS 现金）
4. 利润表勾稽（税/股本/收入明细）
5. 逻辑合理性（增速/毛利/TV/曲棍球杆）
6. 边界情况（0 增长/负 EBITDA）

## 严重级分类
- 致命：BS 不平衡/现金勾稽失败 → 模型不可用
- 重大：硬编码关键假设/单位错配 → 结果可能错
- 一般：颜色/隐藏行列 → 规范问题

## 红旗速查
增速>100%无解释 · 毛利率偏离常态 · TV>75% · 曲棍球杆 · 隐藏行列
