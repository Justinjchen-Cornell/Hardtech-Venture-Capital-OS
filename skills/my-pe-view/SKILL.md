# 我的PE观 · 本土 PE 实战框架

> 来源：2026-08-18 完成 6 单元精读。本 skill = 财务尽调与本土 PE 实战工具。

## 核心框架

### ① PE 十条准则（第四部分）
政策跟随 / 先选赛道再选选手 / 成长性核心 / 市场胜于技术（"获奖级别越高投资可能性越低"）/ 瑕疵vs硬伤 / 增值服务 / 懂经营>懂上市 / 相面术（90%团队问题）/ 谨慎 / 联合投资

### ② 9 数字尽调（尽调强度标准）
90%股东管理层 / 8点钟原则 / 7部门 / 连续6天 / 5要素（团队管理技术市场财务）/ 4上下游客户（验证性考察）/ 3竞争对手 / 20关键问题 / 员工吃饭
本质：信息广度×深度×验证；信息三角验证（供应商×客户×团队）

### ③ 财务挤水分三原则
1. 还原经营之道才是会计本质（账算不出来看物理事实——杀猪案例）
2. 要赚钱不要赚利润（收入>利润；经营性现金流最重要；客户访谈验证收入）
3. 相信常识不要相信奇迹（销售利润率>30% 需特别关注；拐点理论=90% BP 魔术说法）

### ④ 三投资风格（第五部分）
Pre-IPO（一二级差价）/ 双F（Finance+Feeling）/ 行业型（先选赛道再选选手——优势日益凸显）
"任何行业没有壁垒只能获得社会平均利润"——PE 超额利润=行业理解壁垒

### ⑤ 三层市场区分（准则4实战版）
叙事市场（TAM）≠ 可及市场（SAM）≠ 实际市场（SOM）——尽调第一问"实际→叙事路径"
