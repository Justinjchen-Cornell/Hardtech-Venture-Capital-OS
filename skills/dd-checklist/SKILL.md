# 尽调清单（DD Checklist）

> 借鉴：Anthropic financial-services private-equity/dd-checklist。适配中国早中期硬科技（A 轮前、教授创业、科技成果转化）。
> 上游：shou-zheng（三把尺/九原则/六道坎）、my-pe-view（9 数字尽调/挤水分三原则）、pe-dd-handbook（行研 13 要素/迹象投资法）、tech-transfer（职务发明核查/TRL-CRL）。
> 衔接：输出喂给 tech-dd 尽调报告（pipeline/templates/03-技术尽调.md）。

## 核心框架

### ① 定范围（先问再干）
- 目标公司：名称/赛道/商业模式（硬件/软件/混合）
- 项目类型：早期天使-A轮 / 成长期 / 平台整合——决定尽调深度
- 已知关注点：客户集中/技术路线/职务发明/出口管制——优先排序
- 时间表：何时要结论（决定 P0 项）

### ② 六大 Workstream 清单（按赛道裁剪）

**财务 DD**（配合 my-pe-view 9 数字）
- 收入真实性：对账单+凭证+客户访谈三件套；预收/合同/开票三口径核对
- 现金流：经营性现金流是否为正；烧钱率与现金跑道（runway）
- 毛利：毛利率>30% 需验证（成本端/费用分摊/客户价格三件套）
- 收入质量：客户集中度（Top5/Top10）、订单与积压（backlog）、回款周期
- 历史融资与股权结构：cap table、优先权、对赌遗留
- 政府补贴/退税占比：非经常性收入识别

**商业 DD**
- 市场规模与增速（TAM/SAM/SOM）；国产替代空间与进口替代逻辑
- 竞争格局：直接/间接对手、大厂进入时间表（硬科技关键）
- 客户分析：集中度、留存、NPS、POC→量产转化率（硬件）
- 定价权：毛利率趋势、合同结构、降价压力
- 销售管线：意向/合同/预付款三连（订单快检）

**法律 DD**
- 股权结构：代持/境外架构/员工期权（ESOP 是否预留）
- 专利权属：职务发明归属（对照清华样板流程）、共有人、发明人激励
- 重大合同：客户/供应商/联合开发/独家条款
- 诉讼与合规：历史纠纷、行政处罚、军工/涉密/出口管制背景
- 竞业协议：核心团队与上家关系

**运营与 HR DD**
- 组织架构与关键人风险（Key Person 依赖）
- 全职状态核实（创始人是否全职——死亡清单项）
- 薪酬与股权激励：核心团队持股、期权计划
- 供应链：卡脖子环节、单一供应商依赖、备选方案

**技术 DD**（硬科技核心，调用 shou-zheng 技术尺）
- 技术尺九原则：稀缺性/领先性（领先 1-2 年）/平台型 vs 项目型
- 专利质量：核心发明 vs 改进型；权利要求范围；可规避性
- 技术路线代际：当前路线 vs 替代路线（竞争性毁灭三问）
- TRL/CRL 标定（tech-transfer）：两轴错配=策略信号
- 研发投入：研发资本化比例、研发人员占比

**合规与 ESG DD**（按需）
- 数据合规（个人信息保护法/数据出境）；环保/安全/消防
- 出口管制与两用物项；资质证照齐备性

|:--|:--|:--|:--|:--|:--|

状态机：未启动 → 已请求 → 已收到 → 审核中 → 完成 → ⚠️红旗

### ④ 红旗汇总（滚动维护）
- 发现什么 / 哪个 workstream / 严重级（deal-breaker·重大·可管理）/ 缓解路径 / 对估值或条款的影响
- 硬伤（不可修复）与瑕疵（可修复）分栏——对应 shou-zheng ch06 分类

### ⑤ 输出
- 按 workstream 分组的 RFI 请求清单（含优先级与截止）
- 跟踪表（Excel 或 md 表格）
- 红旗汇总（deal-breaker 置顶）
- 每周状态简报：完成率 / 未决项 / 红旗

## 使用提示
- P0 项优先：gating 决策的项目（如职务发明核查）先请求
- 卖方/创始人响应慢 = 红旗信号
- 数据室内容与清单交叉核对找缺口
- 清单是活文档：尽调推进中持续更新
- 与 vault 概念页联动
