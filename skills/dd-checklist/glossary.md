# 术语表（glossary）

| 术语 | 含义 |
|:--|:--|
| RFI | 信息请求清单（Request for Information） |
| QoE | 盈利质量调整（Quality of Earnings） |
| 收入三件套 | 对账单+凭证+客户访谈 |
| 订单三连 | 意向→合同→预付款 |
| 数据室 | Data Room，尽调资料集中存放处 |
| Key Person | 关键人依赖（创始人/CTO 不可替代性） |
| runway | 现金跑道 = 现金余额 ÷ 月度烧钱率 |
| 职务发明 | 执行本单位任务完成的发明，权属归单位（含学校） |
| TRL/CRL | 技术/商业就绪度等级（tech-transfer 双轴） |
