# 专利评估速查 + 案例库

> 升级通道：每项目评估后回填一行——**案例库是技能的核心资产**

## 六维速查
1. 权属法律：发明人/权利人/状态/质押——高校项目先查职务发明
2. 核心识别：哪件被无效=技术崩塌？1-3 件核心+外围为健康
3. Claim 结构：独权宽（方法+装置+系统）vs 窄（锁定参数）；从权纵深
4. 布局体系：时间连续（断层 3 年+=红旗）+ 逻辑层次（核心→外围）
5. 可规避性：配方类天然弱（改配比即绕）；真正壁垒=专利+know-how 组合
6. 国际布局：PCT/美/欧 = 质量经国际审查+出海保护

## 红旗速查
- [ ] 权利人=学校/个人未转让（职务发明）
- [ ] "授权 N 项"混入申请中
- [ ] 全是"一种……方法"同构（凑数）
- [ ] 无核心专利（全外围）
- [ ] 独权锁定具体参数（易规避）
- [ ] 核心专利后 3 年无申请（技术停滞）
- [ ] 专利族无国际布局但声称"全球首创"
