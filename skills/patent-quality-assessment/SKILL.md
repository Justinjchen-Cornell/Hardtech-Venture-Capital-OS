# 专利质量评估（Patent Quality Assessment）

> 来源：2026-09-02 固化为技能 · 示范案例：纵激元 11 项专利评估（04.Projects/纵激元/02-专利质量评估示范）
> 定位：**技术尽调的第二道筛**——物理审查（主张是否反物理）之后，审"壁垒是否真实可持有"
> 升级机制：每项目评估后把"该领域专利布局特征+红旗"回填 cheatsheet 案例库——随项目越用越准

## 核心方法：六维评估框架

### 维度 1：权属与法律状态（合法性）
| 检查项 | 红旗 |
|:--|:--|
| 发明人 = 创始人/核心团队？ | 发明人含无关人员（挂名/学校老师代持）|
| 专利权人 = 公司 or 个人 or 学校？ | 权属在学校/个人未转让——职务发明未处置（高校项目第一雷）|
| 法律状态：有效/实审/驳回/失效？ | "已授权专利 N 项"混入"申请中" |
| 是否有质押/许可/纠纷 | 质押未披露 |

### 维度 2：核心专利识别（root claim）
- 把专利分成：**核心专利**（保护核心技术原理——如"常温半导体脉泽及其应用"）vs **外围专利**（应用/电路实现/工艺细节）
- 判断标准：哪一件被无效掉 = 技术主张崩塌？那件就是核心
- 核心专利数量：健康=1-3 件核心+若干外围；只有外围无核心=红旗

### 维度 3：Claim 结构分析（独权宽度）
| 信号 | 解读 |
|:--|:--|
| 独权宽（方法+装置+系统多层面）| 保护面大 ✅ |
| 独权窄（限定具体参数/具体材料）| 易被规避 ⚠️ |
| 从权数量多且层级清晰 | 防御纵深 ✅ |
| 全部是"一种……方法/装置"同构 | 可能凑数 ⚠️ |

### 维度 4：布局体系（时间与逻辑）
- 时间连续性：核心专利之后是否有持续申请（保护迭代）？断层 3 年+ = 技术停滞或团队流失
- 逻辑层次：核心（原理）→ 外围（电路/工艺/应用）是否成体系？
- 家族一致性：同一技术是否多件专利互相引用/同族？

### 维度 5：可规避性（claim 能否绕过）
- 反向工程测试：若竞品不用你的核心限定（具体参数/材料配比），能否做出同等性能？
- 配方类专利天然弱（难反向但易绕过——改配比即规避）；结构/方法类相对强
- **关键追问**：除了专利，有没有"专利保护不了的部分"（know-how/工艺诀窍/供应链）？——真正的壁垒往往是"专利+秘密"组合

### 维度 6：国际布局
- 有 PCT/美国/欧洲专利 = 面向全球市场+质量经过国际审查 ✅
- 只有中国专利 = 国内市场逻辑（可接受）或出海无保护（风险）

| 1 权属法律 | ... | | |

## 执行纪律
- 评估基于专利**清单+公开检索**（智慧芽/佰腾/国家知识产权局），claim 全文必须读独权
- "专利 N 项"必须区分：授权 vs 申请中 vs 失效
- 专利质量 ≠ 技术质量：专利弱但 know-how 强是常见的（配方类）——两者分开评
- 输出喂给 tech-dd（IP 核查结论）与 verifier（壁垒候选概率）

## 使用提示
- 触发：任何主张"专利护城河/首创/唯一"的项目必做（T2 的实体化）
- 与 physics-feasibility-check 联动：先物理筛（主张真实性）→ 再专利筛（壁垒可持有性）
