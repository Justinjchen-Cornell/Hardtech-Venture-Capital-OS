# 穷查理宝典 · 投资决策操作系统

> 来源：2026-08-17 完成 11 单元精读（正本 4,168 行全覆盖）。本 skill = 个人投资宪法 v1.1 的机器镜像 + 决策工具集。
> 注意：本 skill 是"判断力工具"不是"书摘"——内容为精读产出（宪法/概念页/郑宗良项目素材），原文可回溯行号。

## 核心：8 条铁律（宪法 v1.1）

1. **多元思维模型**：≥3 学科视角才可下投决；模型同向叠加=Lollapalooza，互相抵消=否决信号；验证顺序 技术→市场→团队；权重顺序 团队>市场>技术
2. **三选项分类（能力圈）**：可以/不行/太难；"太难"无论多热门不投（禁 FOMO 改判）；归"可以"必须能说出能力圈边界；剪草工原理（中国窄链路做最懂）
3. **逆向思维（死亡清单）**：先问"100% 会死在哪"；六大死法：现金流断裂/团队内讧/合规事故/技术被颠覆/伪需求/道德风险；任一无法排除=不出手；司机知识三问（为什么/边界/反例）
4. **误判心理学检查**：识别→追问动机→拒绝行动；激励错位看利益不看承诺；热点双重陷阱（认知污染+交易恶化）；BP 打五折；反向观点栏；欢迎坏消息
5. **投后管理纪律**：死亡螺旋（浮亏→否认→隐瞒→恶化）；破局三环节（反转触发器/坏消息机制/独立裁判）；决策只向前看
6. **出手纪律（弹药）**：好球=好项目×好价格×好时机；出手五连问；弹药守恒（乱出手不可逆>坐失良机可逆）；少投重注深跟；接触≠出手
7. **竞争性毁灭**：判断项目=判断技术路线/模式基因的适应度；对手是路线不是公司；三问（适应特征/环境方向/恐龙or哺乳动物）
8. **冲浪模型与彩池纪律**：时机四步（浪形成/谁在浪尖/停留多久/被淹没）；彩池纪律（热门无投注优势，看懂才下注）；护城河动态三问；泡沫判定（价格逻辑=泡沫）
