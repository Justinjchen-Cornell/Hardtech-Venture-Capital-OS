# 决策模式集（patterns）

## P1 赛道初筛三问（三法则）
需求真实升级？物理可行？资源够？——三条件同满足才可能爆发

## P2 范式定位（找创新主战场）
主范式在哪一层？信息层（易复制）/物质层（难复制）/系统层（生态位）→ 可复制性判断

## P3 ESK 结构形态判断
K-S双高 E低 + 提升路径明确 = 可投（智谱同构）；E低路径模糊 = 不投；K分论文型/产品型

## P4 四超难度标定
超复杂/超宏观/超微观/超极端——四超越多周期越长资金越大；超宏观=国家工程级

## P5 核爆点三要素检查（项目尺度）
人才密度×资本密度×资源密度——哪个最接近零？→ 尽调优先级

## P6 两套泵检查（教授创业）
学术泵1（研发正反馈）✅ vs 商业泵2（销售→现金流→再投入）⬜——泵2点火信号=第一个付费客户
