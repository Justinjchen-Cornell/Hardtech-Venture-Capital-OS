# 术语表（glossary）

| 术语 | 含义 |
|:--|:--|
| ARR | 年度经常性收入（Annual Recurring Revenue） |
| NDR | 净收入留存率（Net Dollar Retention，含扩张） |
| 毛留存 | Gross Retention，不含扩张的留存率 |
| CAC | 客户获取成本（Customer Acquisition Cost） |
| LTV | 客户生命周期价值（Lifetime Value） |
| LTV:CAC | 客户价值/获客成本比，>3x 健康 |
| CAC 回本 | 收回获客成本所需月数 |
| 队列 | Cohort，同期进入的客户群（vintage 分析） |
| Magic Number | 新增 ARR ÷ 上期销售市场费用，>0.75x 良好 |
| Rule of 40 | 增速+利润率 >40% 的 SaaS 健康线 |
| take rate | 抽佣比例（交易平台） |
