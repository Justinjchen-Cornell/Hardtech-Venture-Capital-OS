# 守正 · 科技创新投资尽调操作系统

> 来源：2026-08-18 完成 7 单元精读（structured/守正-structured.md）。本 skill = 三把尺子框架的机器化 + 尽调/投后工具集。
> 与 poor-charlie-almanack 联动：穷查理给"道"（8 铁律），守正给"术"（三把尺操作）。

## 核心框架：三把尺子（行 1112-1122）

- **验证顺序：市场 → 技术 → 团队**（先看天花板，成本最低的淘汰器）
- **权重：团队第一**（与穷查理铁律 0 一致）
- **双向多米诺三问**：团队能否支撑技术？技术能否支撑市场？市场能否成就伟大企业？
- 100 个人做 1 天 ≠ 1 个人做 100 天（硬科技靠长期积累）

## 硬科技四分类（U1）
科技 / 高科技 / 硬科技（难以复制）/ 黑科技 / 软科技——"难以复制"是硬科技定义性特征；数字技术（AI）有壁垒则属硬科技
