# 决策表（cheatsheet）

## 三机制速查
1. **5 候选**：最可能/次可能/最坏/最好/意外（风险类含"造假"候选）
2. **概率分布**：Σp=1 · 粒度 0.05 · 尖峰>0.5 下判断 · 平缓≤0.4 降"倾向" · 双峰=无法判断
3. **反向风险**：风险维度从最坏排到最好 · 先问"最坏能否承受"

## 分布形态判定
| 形态 | 判定 |
|:--|:--|
| 尖峰（最高>0.5）| 可下判断 |
| 平缓（最高≤0.4）| 结论降级"倾向" |
| 双峰（两高对立）| 无法判断+缺数据清单 |

## 输出模板（每维度）
候选表(候选/概率/证据/等级) → 分布形态 → 主导强度 → 阈值检验 → 无法判断+缺什么

## 硬规则五条
可溯源数字 · 必给分布 · 风险必反向 · 低阈值标无法判断 · RWP 概率校准
