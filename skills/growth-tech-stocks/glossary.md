# 术语表（glossary）

- **20% 法则**：持续 20%+ 收入增长 = 高增长科技股基本指标
- **四大引擎**：收入/创新/市场空间/用户管理
- **打破中间环节**：创新本质（更快/更便捷/更省钱）
- **规模效应四好处**：用户体验/单位经济/护城河/网络效应
- **核心用户指标**：用户数/集中度/复购（ToB=客户结构）
- **1/3/3 归因**：股价波动归因（基本面/行业/市场）
- **倍数压缩**：估值倍数收缩（基本面兑现也亏钱）
- **打折的优质股**：四问确认优质 + 股价调整 = 买入机会
- **条件句翻译**：口头禅"如果"→ 里程碑条件清单
