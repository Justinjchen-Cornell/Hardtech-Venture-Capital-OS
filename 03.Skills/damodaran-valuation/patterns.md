# 决策模式集（patterns）

## P1 叙事 3P 测试（估值前置）
商业故事 → Possible? Plausible? Probable? → P 级别=估值权重；每轮尽调后重定 P

## P2 失败概率调整（核心公式）
价值 = 存续概率 × DCF + (1−存续概率) × 残值——死亡清单定量化

## P3 VC 估值完整路径（初创）
收入（市场×份额）→ 利润率（→可持续）→ 再投资（sales-to-capital）→ 失败调整 → 期权处理

## P4 谈判四反制（VC 回报率=工具）
自建估值锚 / 区分风险补偿与压价 / 引入竞争（联合投资）/ 里程碑期权替代高折现率

## P5 私有企业调整
Total Beta（未分散化）+ 流动性折价（30-40%）+ Key Person 调整（五件套）

## P6 郑宗良估值调整链
3P(Possible) → 增长型亏损方法 → 初创路径（失败 60%）→ 私有调整（流动性折价+关键人）→ 里程碑跳变条款
