# 决策模式集（patterns）

## P1 条款分类（E/C 二元）
E 主导谈数字 / C 主导谈权力 / E&C 双性拆开谈

## P2 估值表述完全体
"投后完全稀释估值 X（含 Y% 期权池），拟投 Z，占 N%（稀释另计/已含）"——三要素防歧义

## P3 关键条款法（谈判）
五清单（估值/期权池/清算/董事会/投票）寸步不让；非关键（登记权/转让）退十步
"你永远不能在条款上赚到钱"——精力是弹药

## P4 谈判准备三件套
目标清单 / 可让步项 / 底线——谈判前定，不临场发挥

## P5 对手研究
基金结构（管理公司/GP/LP）+ 动机压力（期限/carry/募资）——诉诸利益实操版

## P6 期权池核查
池子多大？谁付费（创始人还是共同）？融资前还是融资后扩大？

## P7 董事会设计
2:2:1 平衡 + 独立席=技术经理人型（懂技术+懂资本+懂产业）+ 表决规则确认
