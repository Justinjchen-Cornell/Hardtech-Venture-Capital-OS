# 术语表（glossary）

- **BMP**：Business（业务）× Management（管理）× Price（价格）
- **大市场/小份额/长优势**：业务质量三特征
- **大德/大才**：管理质量两特征（像所有者思考/懂价值驱动）
- **潜在盈利能力**：调整后真实盈利（成熟收获期口径）
- **前瞻 PE**：用 3 年后盈利算的市盈率
- **EVA**：经济增加值（研发资本化等会计调整）
- **CAC/LTV**：获客成本/客户终身价值（订阅模型）
- **负营运资本**：先卖货后付钱（亚马逊模式）
- **均值回归**：价格回归正常（数字时代失效）
- **市净率**：资产估值指标（数字企业不适用）
