## 估值流程（生命周期匹配）
1. **确定生命周期阶段**：
   - 初创期（无收入/天使-A轮）→ 风险调整的实物期权法 / 里程碑估值法
   - 成长期（收入暴增/微利）→ DCF 远期倍数法 + 相对估值（PS/EV-revenue）
   - 成熟期（利润稳定）→ DCF + PE
   - 数字企业/亏损期 → 潜在盈利能力调整（价值投资3.0 BMP 框架：业务质量 B/管理质量 M/价格 P）
2. **建模要求**：
   - 关键假设显式列出（收入增速/目标利润率/再投资/折现率/退出倍数）
   - 敏感性分析（核心假设 ±20% 的影响）
   - 对标公司对比（可比公司估值区间）
   - 概率加权情景（乐观/基准/悲观）
3. **好球对照**（穷查理纪律）：
   - 好价格检验：该估值下未来 5 年 IRR 假设能否讲清？
   - 彩池检验：这是热门价还是冷门价？我们有无投注优势？
   - 弹药检验：按此估值投，弹药/储备金是否健康？
4. **Young Company 4 步法**（价值投资3.0，待 skill 就绪后补全细节）：
   - 收入增长 → 目标利润率 → 再投资需求 → 概率加权价值

## 输出格式（估值报告）
```
## 估值分析：<项目名>
- 生命周期阶段：<初创/成长/成熟/数字亏损期>
- 估值方法：<方法>（+为什么选它）
- 估值区间：<下限 - 上限>（关键假设：<列出>）
- 敏感性：<核心假设 ±20% 影响表>
- 对标：<可比公司/交易> · 区间：<区间>
- 概率加权：乐观<值>/基准<值>/悲观<值>
- 好球对照：<好价格? / 彩池? / 弹药?>
- 结论：<可投 / 偏贵 / 太贵 / 无法判断>
```
## 输出纪律
- 数字必须可追溯到假设；假设必须显式；禁止"拍脑袋"估值
- 数据不足时输出"无法判断"并列出缺什么数据
