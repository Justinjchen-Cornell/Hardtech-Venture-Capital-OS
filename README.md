# Hardtech-Venture-Capital-OS

> 成都早中期硬科技投资决策操作系统 —— 把 11 本投资经典变成机器可调用的技能 + 项目常驻规则 + 专项子代理，并用一条成都本地项目流水线跑起来。

## 为什么做这个

11 本投资经典（穷查理宝典 / 硬科技浪潮 / 守正 / 下一个风口 / 高科技营销魔法 / 我的PE观 / 高增长科技股投资法 / 价值投资3.0 / Investment Valuation / 私募股权投资和尽职调查手册 / 风险投资交易）是"会背书的顾问"，不是"能找到项目的系统"。本仓库把知识变成三层结构 + 一层业务流水线：

- **CLAUDE.md** —— 投资哲学与决策纪律（每条会话常驻）
- **Skills** —— 11 本书转成的可调用技能（按需加载）
- **Agents** —— 专项子代理（独立上下文，干尽调重活）
- **Pipeline** —— 成都项目池与跟进状态机（业务侧）

## 成都 4+6 候选地图（待验证，不预设焦点）

立足成都"十五五"产业布局作为候选地图，**系统结构赛道无关**，用项目池数据驱动收敛：

- **4 新兴**：新能源 / 新材料 / 低空经济 / 航空航天
- **6 未来**：量子科技 / 生物制造 / 脑机接口 / 氢能与核聚变 / 具身智能 / 第六代移动通信

验证路径：项目池优先收录 10 个方向项目 → 统一评估模板横向比较 → 累计 ≥10 样本后按"样本密集度 × 成都禀赋 × 认知可及性"收敛主轴。

## 项目管线状态机

```
接触 → 访谈 → 初筛 → 尽调 → 估值 → 投决 → 投后 / 归档
```

每个项目一张卡片（`04.Projects/`），字段：赛道标签 / 来源渠道 / 芒格三选项 / 守正三把尺 / 20%法则 / 跟进状态 / 双链。
