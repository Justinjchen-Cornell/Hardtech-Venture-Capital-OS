# 概念：Lollapalooza效应

> **一句话定义：** 当几个思维模型（或心理倾向）联合起来、共同作用同一个方向时，产生远超单一因素之和的极端后果——"数种心理倾向共同作用造成极端后果的倾向"（误判心理学第 25 种）。 [Source: 《穷查理宝典》行1964脚注+行3554, 2026-08-17]

## 直觉类比

台风——单个天气因素（低压、洋流、风切变）都不致命，但叠加在一起就是摧毁性的。市场狂热与投资判断同理：单一因素可容忍，叠加即失控。

## 核心模式

```
正向 Lollapalooza（投资决策时）
  技术壁垒 + 市场爆发 + 生态位 + 团队全职
  → 模型同向 → 值得下重注

负向 Lollapalooza（市场泡沫时）
  社会认同(别人都投) + 激励错位(GP必须投) + 避免不一致(已公开看多)
  → 集体追高 → 高位接盘
```

## 本知识库的实际案例

- **AI 热潮（2023-2026）**：社会认同 + 激励超级反应 + 避免不一致性三倾向叠加，全市场追高大模型项目——典型的负向 Lollapalooza
- **郑宗良项目**：若技术+市场+团队+政策全部通过→正向 Lollapalooza→值得深度尽调；若政策火热但技术平庸→警惕这是负向叠加的开始
