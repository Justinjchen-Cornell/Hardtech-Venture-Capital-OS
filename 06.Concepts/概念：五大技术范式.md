# 概念：五大技术范式（硬科技文明的坐标系）

> **一句话定义：** 《硬科技浪潮》第3章——技术进化三法则（需求牵引/物理约束/资源边界）+ 五大技术范式（信息/能量/物质/空间/生命），判断技术项目在文明尺度上的位置。 [Source: 《硬科技浪潮》第3章 行1054-1106, 2026-08-18]

## 技术进化三法则（赛道初筛三问）
1. 需求牵引力：需求是否真实升级（防伪需求）
2. 物理约束力：物理定律天花板（可行性边界）
3. 资源边界力：92 元素限制/锂钴稀土（卡脖子判断）
三个条件同时满足 → 技术革命爆发

## 五大范式 × 中国 4+6 映射
| 范式 | 4+6 方向 | 中国禀赋 |
|:--|:--|:--|
| 信息 | 6G/量子/具身智能(AI) | 电子科大/中国智算中心 |
| 能量 | 新能源/氢能核聚变 | 通威/宁德四川/东方电气 |
| 物质 | 新材料 | 青白江功能区 |
| 空间 | 低空经济/航空航天 | 试点/成飞/国星宇航 |
| 生命 | 生物制造/脑机接口 | 天府国际生物城 |

## 4+6 的交叉结构（范式坐标系）
- 低空经济 = 空间×信息（通感一体）
- 生物制造 = 生命×物质
- 具身智能 = 信息×空间×物质
- 脑机接口 = 生命×信息
- 航空航天 = 全范式（空间主×信息×物质×能量×生命）⭐
- 郑宗良天线 = 空间×信息×物质 三交叉

## 核心操作
1. 范式定位 = 找创新主战场（信息层易复制/物质层难复制/系统层生态位）
2. 范式交叉密度 = 产业复杂度 = 机会密度 × 判断难度
3. 范式同源方向可合并观察（低空+航天="空间范式族"）
