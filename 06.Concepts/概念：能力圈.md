# 概念：能力圈

> **一句话定义：** 正确的决策必须局限在自己真正了解的领域之内；能力圈必须有明确的边界——"没有边界的能力根本不能称之为能力"。 [Source: 《穷查理宝典》第四章 行1046-1054, 2026-08-17]

## 直觉类比

游泳池的深浅区：不会游泳的人往深水区跳是自杀；会游泳的人也必须知道自己能游多远。更重要的是——深浅区的位置可以通过训练改变，但"不知道自己不会游"的人必死。

## 核心模式

```
三选项分类法（每个项目/方向的入口闸门）：
  可以   —— 能说出能力圈的边界（说不出 = 实际"太难"）
  不行   —— 时机不对 / 资源错配（技术未收敛、监管未定）
  太难   —— 怎么学都够不着（国家队主导、壁垒极高）
        ↓
  "太难" → 无论多热门，不投（禁止 FOMO 改判）

能力圈扩大机制：
  不懂但可学 → 读书+案例+专家网络+样本 → 转为"可以"
  不懂且难学 → 归"太难" → 坚决不碰
  不懂且不该学 → 归"不行" → 过几年再看
```

## 本知识库的实际案例

### 芒格的衍生品（行 1172）
华尔街最赚钱的业务之一，芒格主动归入"太难"拒绝——2008 年金融危机证明其正确。"太难"不是懦弱，是纪律。

### 剪草工原理（行 3064）
"当不了世界级网球手，就当伯米吉最好的剪草工"——对早期硬科技 VC 的生存策略：不在全赛道与红杉竞争，而在成都的窄链路做到最懂。

### 2026-08-17 用户练习
对集成电路/商业航天/生物制造三个方向答"我都不懂，但愿意学习"——诚实承认边界 = 能力圈纪律的第一步；系统（11 本书+子代理+样本）的作用是把"不懂但可学"的领域系统性地转为"可以"。
