# 概念：叙事与数字（Story to Value + 3P 测试）

> **一句话定义：** 《Investment Valuation》Ch13——估值 = 叙事 + 数字的桥梁；四步流程（商业故事→3P 测试→估值输入→价值）——达摩达兰的核心方法论。 [Source: Investment Valuation Ch13, 2026-08-18]

## 核心命题
- "电子表格数字汇编 = 财务模型不是估值；只有故事 = 叙事不是估值"
- 两种偏科失败：虚假精确（数字派）/ 童话（叙事派）
- 要求：自律的讲故事者 or 富有想象力的数字计算者

## 三大故事危险
情绪左右（听众暂停怀疑）/ 记忆不可靠 / 童话（希望取代预期）/ 失控故事（忽略重大缺口）

## 四步流程
1. 构建商业故事（简单/可理解）
2. **3P 测试**：Possible → Plausible → Probable（测试越来越严格）
3. 故事→输入：增长（单位×价格）/ 风险（资本成本+失败风险）/ 现金流
4. 输入→价值（收入→利润→FCFF→折现→终值→每股，含失败调整）

## 核心操作：P 级别 = 估值权重
- Possible → 低概率+大失败调整；Probable → 接近确定性
- P 升级路径 = 尽调里程碑（Possible→Plausible 需路径证据；→Probable 需订单数据）
- 每轮尽调后重新定 P，P 不升级估值不推进

## 本知识库的实际案例
- 郑宗良（2026-08-18）：叙事"低空通感一体国产替代"处于 Possible——估值权重=低概率×大价值−大失败调整；升级路径=市场落差路径+订单三连
