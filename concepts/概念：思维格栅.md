# 概念：思维格栅

> **一句话定义：** 把各学科的核心模型组织成相互连接、交叉验证的格栅状知识结构——多元思维模型的组织形态与学习方法。

## 直觉类比

独立抽屉 vs 网格书架：抽屉各自封闭，取用互不相干；书架横竖相连，一本书的位置总被相邻书目提醒。知识如果存在"抽屉"里，调用时想不到另一学科；存在"格栅"里，一个问题自然触发多学科视角。

## 核心模式

```
模型入库（格栅构建）：
  ① 每学科只取"重要理论"（共约100个，几个至关重要）
  ② 模型之间找连接点（例：网络效应=经济学×信息科学）
  ③ 用真实项目反复挂载（每看一个项目就往格栅上挂一次）

模型调用（格栅使用）：
  一个问题 → 沿格栅触发相邻模型 → 交叉验证
  例：技术先进（工程学）≠ 市场买单（经济学）→ 交叉检验
```

## 本知识库的实际案例

- **郑宗良项目**：技术问题用工程学+经济学双重检验（先进技术若无市场接受度，工程判断无效）；竞争问题用生物学（生态位）+经济学（客户集中度）交叉
- **体系建设**：sector-scanner / tech-dd / valuation-analyst 三个子代理 = 格栅的机器化形态（每个代理一个学科视角，输出汇合即交叉验证）
