# 概念：逆向思维（死亡清单法）

> **一句话定义：** 先研究"怎么失败"，再研究"怎么成功"——"要知道我会死在哪里，我就永远不去那个地方"；投决的本质是排除法，不是证明法。 [Source: 《穷查理宝典》附录第二讲 行3368-3370, 2026-08-17]

## 直觉类比

乡下人不知道自己要什么，但清楚地知道自己不想死在哪——那就永远不去那儿。投资同理：证明"能成"很难，排除"会死"容易。

## 核心模式

```
逆向三步法：
  ① 列死亡清单（这个项目 100% 会死在哪？6 个死法全过一遍）
  ② 验证生命线（排除死法之后，才谈凭什么活下来）
  ③ 排序（先排致死项，再谈加分项；任一死法无法排除 = 不出手）

科技项目六大死法：
  现金流断裂（活不到验证点）/ 团队内讧 / 合规事故
  技术被颠覆 / 伪需求 / 创始人道德风险

死因倒推链（从症状到病因）：
  现金流断裂 ← 无订单 ← 市场验证未做 ← 只做了技术验证
  → 验证动作提前做掉（客户访谈/意向订单/预付款）
```

## 本知识库的实际案例

### 郑宗良天线项目（2026-08-17 练习）
用户选"现金流断裂"（只有技术方案，无资金计划+储备订单）→ 倒推链：现金流断 ← 无订单 ← 市场验证未做 → 尽调第一眼 = 报告里有无真实客户访谈/意向订单。

### 芒格衍生品（单元 2 关联）
"我们不做这种事情——因为这太难了" = 逆向思维的另一种形态：先排除自己会死的游戏。

### 普朗克知识 vs 司机知识（尽调尺子）
真懂（普朗克）能解释原理/边界/反例；假懂（司机）只会复述结论。问"为什么/边界/反例"三连即可区分——防"司机知识"型创始人。
